# MERN E-Commerce Website

A full-stack MERN e-commerce project built by following a structured video tutorial.  
This repository currently contains the **frontend implementation completed up to 2 hours 45 minutes and 56 seconds** of the tutorial.

---

## 🚀 Project Overview

This project is a modern fashion e-commerce website featuring:
- Product browsing
- Category filtering
- Search functionality
- Best Seller section
- Responsive UI
- Context API state management

Frontend is built using **React + Tailwind CSS**, with backend planned using **Node.js, Express, and MongoDB**.

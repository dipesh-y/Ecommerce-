# MERN E-commerce Project

This is a full-stack e-commerce project built using the MERN stack.

## Progress So Far
- React frontend setup completed
- Tailwind CSS integrated
- Routing implemented using React Router
- Navbar and core layout added
- Home page and Best Seller section implemented
- Product listing UI started
- Context API integrated for product state

## Tech Stack
- React
- Tailwind CSS
- React Router
- Context API
- Node.js (upcoming)
- MongoDB (upcoming)
